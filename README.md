# Sales Forecasting using Machine Learning

## Overview
This project predicts future sales based on historical sales data using machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Workflow
1. Data preprocessing
2. Exploratory Data Analysis
3. Feature engineering
4. Model training
5. Evaluation and prediction

## Skills Demonstrated
- Data analysis
- Regression techniques
- Data visualization
- Machine learning using Scikit-Learn
